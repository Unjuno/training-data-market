# Training Data Market — ビジュアルデザイン・体験仕様 v0.6

**状態:** 実装済みのWebフロントエンドデザイン。対象はローカルDEMOと `/` のライブAPI画面。Sites本番デプロイは別工程。

## 1. 体験の芯

AIモデルを使う「プレイヤー」を、モデルの訓練に関わる「研究参加者」へ変える。中心操作は画像を**探す → 判断する → 推薦する**こと。投票がモデルに及ぼした影響は対照実験によって表示する。研究らしい信頼性と、ゲームとしての高揚感を両立させる。

## 2. デザインの方向

- **トーン:** 実験室 × 研究コックピット。既製の管理画面や暗号資産取引所を模倣しない。
- **タイポグラフィ:** 日本語はシステム/Noto Sans JP。大きな編集的見出しと、測定値用等幅フォントを明確に使い分ける。
- **色:** Midnight `#090f14`（背景）、Panel `#10191e`（カード）、Primary `#c1f575`（アクション・注目）、Muted `#8fa29e`、Warning `#ffb77e`。鮮やかな色は主要操作だけに使用。
- **造形:** 低コントラストのグリッド、補助線、ラウンド番号、角の丸いコンポーネント。現実のCIFAR画像が利用できない場合は抽象代替アートと「画像非公開」を必ず併記。

## 3. 情報の優先順位

1. **今回のクエスト:** モデルが混同する2クラスと、参加者が何を改善すべきか。
2. **モデルの状態:** 検証Loss、Accuracy、ラウンド、個人の推薦上限。実数は取得できた場合のみ。
3. **探索:** 入力欄・クラス絞り込み・誤分類フィルタ・ページングを備える画像カード一覧。
4. **自分の選択:** 画面右に独立した推薦ボード。カードから推薦/解除し、理由を保存。
5. **結果:** Community vs Randomの同一初期状態からの比較。勝敗と採用判定を分離。
6. **ルール:** 観察→推薦→学習→検証の4段階を簡潔に説明。

## 4. コンポーネント / 状態

| 対象 | 正常状態 | 代替・例外状態 |
|---|---|---|
| 上部バッジ | `LIVE · 実測値` | `DEMO · 模擬データ` または `未初期化` |
| モデル指標 | APIで取得したLoss / Accuracy | `—` を表示し、推測値で埋めない |
| 画像カード | 権利確認済みの32×32 RGBをpixelated表示 | 抽象サムネイルと `画像非公開` |
| 画像推薦 | 押下でAPI保存／ローカルデモは編集中 | 上限10・締切後は追加不可 |
| 結果表示 | 検証値・改善量・モデル採否 | 学習未実施なら明示的な空状態 |
| 誤分類フィルタ | 同一checkpointの推論がある場合のみ有効 | 推論なしならAPIエラーを説明 |

## 5. レスポンシブ設計

| 幅 | レイアウト |
|---|---|
| 1360px以上 | ヒーロー2カラム、探索3カラム、右サイドの推薦ボードをsticky配置 |
| 851–1360px | ヒーロー幅を縮小し、必要に応じて探索2カラム |
| 621–850px | ヒーローと推薦ボードを縦積み、探索は最大3カラム |
| 620px以下 | メトリクス2×2、画像カード2列、操作はタップ領域優先 |
| 390px以下 | 画像カード1列、フィルタと入力欄は折り返す |

モバイルの推薦ショートカットはヒーローが画面外に出た後のみ表示し、推薦ボードを表示中は非表示。スクリーンリーダー向けライブリージョン、フォームラベル、`aria-pressed`、キーボードフォーカス、動きの低減設定に対応する。

## 6. 設計上の禁止事項

- プレビューの模擬Lossを「実測」と偽装しない。
- CIFAR-10の権利が未確認なら画像の再配布をしない。
- `推薦しました` をモデル更新完了の意味で使わない。
- 全画像43,000件を一括読み込みしない。APIの最大48件ページングを尊重する。
- Sitesでは見た目だけのモックを完成と主張せず、認証・投票永続化・学習ワーカーの接続状況を個別に報告する。

## 7. QA条件

- ブラウザ描画：1440 / 820 / 390px の画面幅で横スクロールなし。
- コントロール：推薦のON/OFF・検索・絞り込み・ページング・推薦理由の保存。
- 失敗表示：APIなし、画像権利未承認、候補0件、締切後、推薦10件上限。
- ソーステスト：Node.js、Pythonの既存テストを維持。ブラウザ検査は隔離したHTML描画環境のため、公開後の実サイトE2Eを別途実施。
